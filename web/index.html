05 — THE METHOD?

How the hunter thinks.

01 / ENCODE

Each candidate is a permutation of 0…n−1. No duplicate values, no invalid test cases.

02 / SCORE

Instrument real sorting implementations. Each element comparison increases the fitness score.

03 / EVOLVE

Keep elites, select strong parents with tournaments, combine their orders, then mutate.

04 / CHALLENGE

Compare against random search with an equal number of evaluations. Evolution is not guaranteed to win.

↳ NO PAID MODEL. NO PRETEND AI.

This is an evolutionary optimization algorithm, not a neural network or an LLM. The fitness metric is deterministic comparisons, not noisy wall-clock time. Experiments execute entirely on your device using Python via Pyodide/WebAssembly.
